Investo API v1

Public REST API for stocks, forex, market data, and news. JSON responses, no authentication required.

Stocks

GET /api/v1/stocks

List all stocks with latest prices and filtering.

ParamTypeDescription
sectorstringFilter by sector ID or slug
searchstringSearch by code or name
pageintPage number (default: 1)
limitintItems per page (default: 50, max: 200)
sort_bystringprice, change, market_cap
sort_orderstringasc or desc
 
curl -X GET "http://localhost:8000/api/v1/stocks?sector=1&page=1&limit=10&sort_by=price&sort_order=desc" \
  -H "Accept: application/json"
GET /api/v1/stocks/{code}

Single stock detail with latest price, fundamentals, and sector.

ParamTypeDescription
codestringStock code (e.g. BBCA, TLKM, ASII)
 
curl -X GET "http://localhost:8000/api/v1/stocks/BBCA" \
  -H "Accept: application/json"
GET /api/v1/stocks/{code}/prices

Historical price data with interval aggregation.

ParamTypeDescription
startdateStart date (YYYY-MM-DD)
enddateEnd date (YYYY-MM-DD)
intervalstring1d, 1wk, 1mo
 
curl -X GET "http://localhost:8000/api/v1/stocks/BBCA/prices?start=2026-01-01&end=2026-08-02&interval=1mo" \
  -H "Accept: application/json"
GET /api/v1/stocks/{code}/fundamentals

Fundamental data history for a stock.

ParamTypeDescription
limitintNumber of periods (default: 40)
 
curl -X GET "http://localhost:8000/api/v1/stocks/BBCA/fundamentals?limit=8" \
  -H "Accept: application/json"
GET /api/v1/stocks/{code}/indicators

All technical indicators: SMA, EMA, RSI, MACD, Bollinger Bands, Stochastic, ATR.

ParamTypeDescription
periodintData period in days (default: 730)
 
curl -X GET "http://localhost:8000/api/v1/stocks/BBCA/indicators" \
  -H "Accept: application/json"
GET /api/v1/stocks/{code}/patterns

Detected candlestick patterns with reliability scores.

ParamTypeDescription
limitintMax patterns to return (default: 20)
 
curl -X GET "http://localhost:8000/api/v1/stocks/BBCA/patterns?limit=5" \
  -H "Accept: application/json"

Authentication

The API v1 is public — no authentication is required. All endpoints return market data freely.

For future authenticated endpoints (portfolio, watchlist, alerts), an API key header X-API-Key will be required.

Rate Limiting

TierPublic
Rate100 requests per minute per IP
HeaderX-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset

Response Format

{
  "success": true,
  "data": { ... },
  "meta": {
    "page": 1,
    "limit": 50,
    "total": 54
  },
  "timestamp": "2026-08-02T12:00:00Z"
}

All timestamps are in UTC ISO 8601 format. Dates use 2006-01-02 format.
