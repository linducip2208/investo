Pertanyaan Umum

Semua pertanyaan yang sering ditanyakan tentang Investo, saham, forex, dan cara menggunakan aplikasi.

Investo adalah platform analisa saham dan forex untuk investor Indonesia. Kami menyediakan chart teknikal, data fundamental IDX, stock screener, portfolio tracker, price alert, berita pasar, dan berbagai tools analisa lainnya dalam satu dashboard terintegrasi. Investo dirancang untuk investor ritel — dari pemula hingga profesional.

Ya, Investo memiliki paket Free yang bisa digunakan selamanya tanpa biaya. Paket Free mencakup watchlist 20 saham, basic chart, 5 price alert, dan 1 portfolio. Untuk fitur lebih lengkap seperti unlimited portfolio, full indicator, screener, dan data fundamental, tersedia paket Pro seharga Rp 99.000/bulan. Anda bisa mencoba Pro gratis selama 14 hari.

Data saham berasal dari Bursa Efek Indonesia (IDX) dan sumber publik yang terpercaya. Kami mengambil data harga, laporan keuangan, corporate action, dan informasi perusahaan dari sumber resmi. Perlu dicatat bahwa data harga mungkin memiliki delay (bukan real-time streaming) untuk paket Free. Data fundamental diperbaharui setiap kuartal sesuai jadwal rilis laporan keuangan emiten.

Investo adalah platform analisa, bukan platform trading. Anda tidak bisa membeli atau menjual saham langsung melalui Investo. Untuk melakukan transaksi jual-beli saham, Anda tetap perlu menggunakan aplikasi sekuritas yang terdaftar di OJK. Investo membantu Anda melakukan analisa sebelum mengambil keputusan trading di sekuritas Anda.

Buka menu Screener dari sidebar. Anda akan melihat 15+ filter yang bisa diatur: sektor, market cap, PER (misal: di bawah 15x), PBV, ROE (misal: di atas 15%), EPS growth, dividend yield, DER, current ratio, dan lainnya. Atur filter sesuai kriteria Anda, lalu klik "Terapkan". Hasil akan muncul dalam tabel yang bisa disort. Klik "Simpan Screener" untuk menyimpan kriteria agar bisa digunakan kembali.

PER (Price to Earnings Ratio): Rasio harga saham terhadap laba per saham. PER rendah bisa mengindikasikan saham undervalued, tapi perlu dicek konteks industrinya.
PBV (Price to Book Value): Rasio harga saham terhadap nilai buku per saham. PBV di bawah 1 berarti saham diperdagangkan di bawah nilai buku asetnya.
ROE (Return on Equity): Persentase laba terhadap ekuitas. ROE tinggi (>15%) menandakan perusahaan efisien dalam menghasilkan laba dari modal pemegang saham.

Masuk ke menu Alert, klik "Buat Alert Baru". Pilih saham dari daftar, tentukan kondisi (misal: harga naik di atas 5.000), masukkan harga target, dan pastikan email Anda sudah terverifikasi. Setelah alert aktif, sistem akan mengirimkan email otomatis begitu harga saham mencapai target. Anda bisa membuat hingga 5 alert di paket Free, unlimited di paket Pro.

Investo menyediakan data 12+ pasangan forex: Major pairs (EUR/USD, GBP/USD, USD/JPY, USD/CHF, AUD/USD, NZD/USD, USD/CAD) dan Exotic pairs dengan Rupiah (USD/IDR, EUR/IDR, SGD/IDR, JPY/IDR, AUD/IDR). Data rate diperbaharui secara berkala. Chart, kalkulator konversi, dan historical data tersedia untuk semua pair.

Ya, keamanan data adalah prioritas kami. Semua data portfolio, transaksi, dan informasi pribadi Anda disimpan dengan enkripsi di database yang aman. Password disimpan menggunakan bcrypt hashing. Koneksi menggunakan HTTPS/SSL. Kami tidak membagikan data Anda ke pihak ketiga. Baca Kebijakan Privasi kami untuk informasi lebih detail.

Anda bisa membeli source code lengkap aplikasi Investo melalui halaman Beli Aplikasi Saham. Tersedia 3 paket: Source Code Only (Rp 2.499K), Source Code + Setup (Rp 3.999K), dan Whitelabel Package (custom). Pembayaran melalui transfer bank. Setelah pembayaran dikonfirmasi, Anda akan mendapatkan akses ke repository Git private dan dokumentasi lengkap.

Saat ini Investo adalah web application yang fully responsive — artinya Anda bisa mengakses semua fitur dari browser HP (Chrome/Safari) tanpa perlu install aplikasi. UI sudah dioptimasi untuk layar kecil. Aplikasi native Android/iOS ada di roadmap kami, tapi untuk sekarang web app sudah memberikan pengalaman yang optimal di mobile.
